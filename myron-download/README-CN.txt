使用方法
1. 解压“小型合并工具包”，将 MERGE.cmd、merge_parts.py、parts.json 放在同一目录。
2. 下载全部 22 个分卷 myron-root-part00.zip 至 myron-root-part21.zip，放到上述同一目录。
   分卷不需要手动解压。也支持已解压的 .zip.part00 等原始分卷。
3. 使用 NTFS 磁盘，合并前至少留 11 GB 可用空间；安装 Python 3.11 或更新版。
4. 双击 MERGE.cmd。程序逐卷检查 SHA256，再校验合并后完整 ZIP 的 SHA256。
   缺卷或坏卷会明确标出编号，只需重下该卷；其它分卷不会被删除。
5. 显示 SUCCESS 后，将合并的 ZIP 放到此前 Windows 测试工具目录，继续 MYRON-IOS27.cmd 的选项 1 → 2。

本工具只合并电脑上的文件，不连接或操作手机。
不要重命名分卷，不要使用浏览器自动追加的“(1)”文件名。
合并后的 ZIP 仍约 10.36 GB，随后解压测试包还需约 15.4 GB 空间。
完整 ZIP 校验成功后，可以自行删除 22 个分卷以腾出空间；脚本不会自动删除它们。
